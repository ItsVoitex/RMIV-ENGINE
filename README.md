# RMIV Engine

RMIV Engine is a work-in-progress game engine written in Rust using OpenGL. there also is an example game built with the engine called **Zombie Dash**.

![Zombie Dash](Assets/zombie-dash.png)

> The engine is still under development. Features, systems, structure will definely.


# SetUpGuide
git clone https://github.com/ItsVoitex/RMIV-ENGINE.git
cd RMIV-ENGINE


Getting Started

Follow the Setup guide to ensure your development environment is set up correctly. Once set up, you can quickly try out the example by running the commands
# Run the app
cargo run -p ZombieDash

# Build a release binary
cargo build -p ZombieDash --release
